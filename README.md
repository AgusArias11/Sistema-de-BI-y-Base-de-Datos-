# Sistema-de-BI-y-Base-de-Datos-
Modelado transaccional y construcción de un modelo BI, implementando vistas analíticas para la toma de decisiones.

# Tecnologías
- SQL Server
- T-SQL
- Modelo Relacional
- Modelo Dimensional (Star Schema)

# Funcionalidades
- Diseño de base de datos transaccional.
- Migración desde tabla maestra.
- Stored Procedures.
- Triggers e índices.
- Modelo de Inteligencia de Negocios.
- Tablas de hechos y dimensiones.
- Vistas para indicadores de negocio.

# Indicadores implementados
- Ticket promedio.
- Distribución de facturación.
- Ranking de solicitudes.
- Anticipación promedio.
- Tasa de aceptación.
- Cotización promedio.
- Tiempo promedio de respuesta.
- Desvío de presupuesto.
- Ranking de aspectos.
- Satisfacción por agente.
